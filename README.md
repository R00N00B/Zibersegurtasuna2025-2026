## 1. Aurkezpena

2025-2026 ikasturteko memoria web-egitura honetan antolatuko da. Helburua da edukia modu argian aurkeztea eta urtean zehar sortutako jarduera, material eta emaitzen jarraipena egitea.

### 1.1 Lan taldea

Atal honetan ikasturteko lantaldeko kideak eta rol nagusiak gehituko dira.

## 2. 2025-2026ko zifrak

Atal honetan urteko adierazle nagusiak argitaratuko dira: parte-hartzea, egindako saioak, eta lortutako emaitzen laburpena.

## 3. Lan ildoak

### 3.1 Lanketa teorikoak

Ikerketa, txosten, eta marko teorikoen azterketak biltzeko atala.

### 3.2 Pilotuak

Ikastetxeekin edo enpresekin egindako pilotu teknikoen deskribapena eta ondorioak.

### 3.3 Ikastaroak

Formazio-saioen laburpena, helburuak, eta erabilitako materialerako estekak.

### 3.4 Zentroetako proiektuak

Ikastetxeetan garatutako proiektu praktikoen jarraipena eta emaitzak.

### 3.5 Jardunaldiak

Urteko topaketa, aurkezpen eta zabalkunde-jardueren egitura.

### 3.6 Txapelketak eta CR saioak

Lehiaketa, simulazio eta entrenamendu saioen antolaketa eta ebaluazio orokorra.
